# 🧩 Repository & Service Pattern with Spring Boot
🎯 **Goal**  
This project applies the **Repository** and **Service** design patterns in a Spring Boot application.  
It implements a clean separation between business logic and data access, adds validation for duplicate emails, and includes **unit testing with Mockito** to ensure code reliability.

---

## ⚙️ Technologies

- **Java 21**
- **Spring Boot** (Web, DevTools)
- **Maven**
- **JUnit 5 + Mockito**
- **Postman** (for manual testing)
- **Git + GitHub** (for version control)

---

## 🧱 How to use


## 1️⃣ Clone the Repository

```bash
git clone https://github.com/pantalois/Tasca_S4.01_Introduccio_a_Spring_Boot.git
cd Tasca_S4.01_Introduccio_a_Spring_Boot
```

## 2️⃣ Install Dependencies

```bash
mvn clean install
```

## 3️⃣ Run the Application

### Option A – Run directly with Maven

```bash
mvn spring-boot:run
```

### Option B – Build and run the JAR

```bash
mvn clean package
java -jar target/userapi-0.0.1-SNAPSHOT.jar
```

## 4️⃣ Run Tests

```bash
mvn test
```
